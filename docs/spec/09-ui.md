## 2. 時間制御

| 操作 | キー | 動作 |
|---|---|---|
| 一時停止 / 再開 | Space | |
| 速度 | 1〜6 | 1x / 2x / 4x / 8x / 16x / 32x |
| 1 tick ステップ | . | 一時停止中のみ |
| 10 秒戻る | ← | スナップショットから再生 |
| 10 秒進む | → | 早送り |
| 巻き戻しスクラブ | タイムラインをドラッグ | 保持スナップショット間を移動 |

一時停止中も命令は出せる（次の再開時に発令される）。

タイムラインには**重要イベントのマーカー**が打たれる。
「左翼が崩壊」「騎兵が突撃」「橋が完成」など。クリックでその時点へ。

## 4. 憑依と命令

### 4.1 憑依

任意の `CommandNode` を選び、「憑依」ボタン（またはキー `E`）。

憑依中:

- **視界がその指揮官の `Blackboard` に制限される**（オプションで解除可能）。
  見えていない敵は表示されないか、最終観測位置に半透明で「推定」として出る
- その指揮官の権限で、直属の子ノードにのみ命令を出せる
- 出した命令は**伝令として実際に伝わる**。即座には届かない
- 憑依を解除すれば全知の観戦者に戻る

これにより「総大将として全体を動かす」と「一隊長として目の前をどうにかする」の
両方の視点を体験できる。

### 4.2 命令の出し方

| 命令 | 操作 |
|---|---|
| 移動 | 対象ノードを選択 → 地図上を右クリック → 向きをドラッグで指定 |
| 陣形変更 | 陣形パネルから選択（変更所要時間が表示される） |
| 攻撃 | 敵 Unit を右クリック → アプローチ方式を選択 |
| 突撃 | 敵 Unit を Shift + 右クリック（騎兵のみ） |
| 側面攻撃 | 敵 Unit を右クリック → 「左側面へ」「右側面へ」 |
| 保持 | H。追撃可否をトグル |
| 退却 | 集結点を右クリック → 「戦闘退却」か「離脱」 |
| 予備指定 | R。集結点を指定 |
| 射撃指示 | 目標エリアを右クリック → 斉射 / 自由 / 射撃中止 |
| 工兵タスク | 工兵 Unit を選択 → タスク種別 → 地図上に線分/範囲を描く |
| 交戦規則 | パネルのトグル（追撃禁止 / 退却禁止 / 自由交戦） |

命令には**条件付きトリガ**を付けられる。

```
「敵が橋を渡り始めたら、騎兵を突撃させよ」
→ Charge { target: enemy_vanguard }
   conditions: [EnemyEnters { area: bridge_area }]
```

条件付き命令は伝令で事前に伝えておき、条件成立時に受け手が自分で発動する。
中世の指揮の限界を回避する現実的な手段だった。

### 4.3 命令の可視化

- 発令された命令は SVG の矢印で表示される
- **伝令が移動中は破線**、届いたら実線
- 受け手が命令を歪めた・無視した場合、矢印が黄色（部分遵守）または赤（無視）になり、
  イベントログに理由が出る
- 命令はキャンセルできるが、既に届いていれば「取り消しの伝令」を送ることになり
  さらに遅延する

## 6. 統計と分析

会戦中・終了後に見られるグラフ。

| グラフ | 内容 |
|---|---|
| 兵力推移 | 両軍の生存・負傷・敗走の推移 |
| 士気推移 | 部隊ごとの平均士気。崩壊の瞬間が見える |
| 疲労推移 | 疲労が勝敗に効いた度合いが分かる |
| 損害の内訳 | 白兵 / 射撃 / 突撃 / 圧死 / 追撃 の割合 |
| 損害の空間分布 | ヒートマップ。どこで人が死んだか |
| 弾薬消費 | 矢の消費と補給の推移 |
| 指揮遅延 | 命令の発令から実行までの平均時間（部隊ごと） |

**損害の内訳で「追撃」が大半を占める**なら、シミュレーションは
中世会戦を正しく再現できている。これは検証指標でもある（01 章 7 節）。

## 7. 観戦モード

`O` キーで自動カメラ。UI を全て隠し、映画的に会戦を追う。

カメラは以下のスコアで注目点を選ぶ。

```
score(location) =
      交戦密度         × 3
    + 士気崩壊の発生   × 8      // 部隊が折れた瞬間は最も面白い
    + 騎兵突撃の接触   × 6
    + 指揮官の死       × 7
    + 大量の死傷の発生 × 4
    - 直前まで見ていた × 5      // 同じ場所を見続けない
```

注目点が変わるとき、カメラは**滑らかに移動する**（数秒かけて）。
瞬間移動はしない。ズームレベルも状況に応じて選ぶ（突撃の接触は L1、
全体の崩壊は L3）。

## 8. リプレイ

### 8.1 保存形式

```json
{
  "version": 1,
  "world_seed": "0x5EED1234ABCD",
  "scenario_hash": "sha256:...",
  "scenario": { /* シナリオ定義そのもの */ },
  "commands": [
    { "tick": 1200, "node": 14, "intent": { "MoveTo": { ... } } },
    { "tick": 3400, "node": 22, "intent": { "Charge": { "target": 51 } } }
  ],
  "final_hash": "0x8A3F..."
}
```

数 KB。共有可能。読み込むと最初から再生される。

`final_hash` は決定論の検証に使う。再生結果のハッシュが一致しなければ、
バージョン間の非互換をユーザーに警告する。

### 8.2 再生

- 再生中も自由にカメラを動かせる（観戦なので）
- 再生中に命令を出すと、そこから**分岐**する（「もしあの時こうしていたら」）。
  分岐したリプレイは新しいリプレイとして保存できる
- 巻き戻しは 02 章 7 節のスナップショット機構を使う

## 9. アクセシビリティと操作性

- 全操作にキーボードショートカット
- 色覚多様性に配慮した陣営色（既定は青 / 赤ではなく、青 / 橙）。設定で変更可
- UI テキストは i18n 対応（日本語 / 英語）。地名・人名も生成時に言語を選ぶ
- モーション軽減設定（カメラの慣性・画面揺れを無効化）
- 描画品質のプリセット（低スペック端末では L0 のアニメーションとエフェクトを削る）
