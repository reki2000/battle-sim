# battle-sim 仕様書

中世ヨーロッパの会戦を、**兵士1人単位・最大数万人**でブラウザ上でシミュレートする。
地形は自動生成され、指揮官・隊長・兵士がそれぞれ独立した思考ルーチンを持って行動する。

## 確定した設計方針

| 項目 | 決定 |
|---|---|
| 実装スタック | Rust → wasm (wasm-bindgen)、UI は TypeScript |
| 描画 | WebGL2 中心 + Canvas2D/SVG/HTML の UI オーバーレイ |
| プレイ形態 | 観戦 + 任意の指揮官に憑依して命令を出せる |
| AI 粒度 | 階層 LOD（全員が個体、思考頻度を状況で 0.5〜10 Hz に可変） |
| 決定論 | 固定小数点で完全決定論（シード + 命令ログで完全再現） |
| 編成モデル | 汎用 N 階層エンジン + データ駆動の中世プリセット |
| 地形 | シード指定の完全プロシージャル生成 |
| 白兵戦 | 個体衝突 + 押し合い + 個人士気の伝播 |
| 工兵 | 野戦築城 / 地形改修 / 攻城兵器 / 兵站支援（すべて） |
| 性格 | 連続パラメータ + アーキタイプ名 |
| アート | ビルド時に手続き生成（タイルアトラス・兵士スプライト） |
