# 07. 工兵

工兵（sapper / pioneer）は 4 つの領域を担当する。すべて第一版に含める。

1. 野戦築城（杭・堀・鹿砦・土塁）
2. 地形改修（架橋・渡渉点整備・伐採）
3. 攻城兵器の野戦運用（投石機・バリスタ）
4. 兵站支援（矢の補給・負傷者回収・修理）

## 1. 作業システム

### 1.1 タスク

```rust
pub struct EngineerTask {
    pub id: TaskId,
    pub kind: TaskKind,
    pub area: Area,             // 対象範囲（線分 or 矩形 or 点）
    pub assigned: NodeId,       // 担当する工兵 Unit
    pub work_required: u32,     // 必要工数（man-seconds）
    pub work_done: u32,
    pub priority: u8,
    pub state: TaskState,       // Queued | InProgress | Done | Abandoned
}
```

### 1.2 工数の消費

```
work_per_tick = Σ over 作業中の工兵 of (
      base_rate
    × (attrs.strength + 128) / 256
    × (1 - fatigue / 12000)
    × terrain_work_mult(surface)      // 岩盤は掘りにくい、泥は掘りやすい
    × weather_mult                     // 凍土は掘れない
    × tool_mult                        // 工具の有無
)
```

工兵は作業中 `State::Working`。**武装は貧弱で、襲われれば逃げる**。
護衛なしの工兵を前線に出すのは危険。

### 1.3 中断と再開

作業は敵の接近で中断される（`self_preservation` の判定）。
`work_done` は保存されるので、後で再開できる。作業中に完成した部分は
そのまま効果を持つ（半分掘れた堀は半分の効果）。

## 2. 野戦築城

| 建造物 | 工数 | 効果 |
|---|---|---|
| **杭列** Stakes | 30 man-s / m | 騎兵の忌避判定を極端に厳しくする。突撃してきた馬に大ダメージ。歩兵は減速 −40%、通過可 |
| **堀** Ditch | 250 man-s / m | 幅 2 m 深さ 1.5 m。移動 −70%、隊列維持 −60%、渡る間の防御 −40%。騎兵は進入不可 |
| **鹿砦** Abatis | 120 man-s / m | 伐採した木を組む。森の近くでのみ作れる。騎兵不可、歩兵 −60% |
| **土塁** Rampart | 400 man-s / m | 高度 +1.5 m。上に立つ側に防御 +30%、射撃の高度ボーナス。堀とセットで作ると効率的（掘った土を使う） |
| **パヴィス設置** | 20 man-s / 枚 | 弩兵用の大盾。射撃時の被弾を大幅減 |
| **馬防柵** Palisade | 200 man-s / m | 杭列の強化版。騎兵完全阻止、歩兵は乗り越えに時間 |

### 2.1 弓兵の自己築城

長弓兵は自分で杭を打てる（歴史的にアジンクールで実施）。

- 各長弓兵が携行する杭 1 本。設置に 60 秒
- 工兵ほど効率的ではないが、部隊全体で一斉に打てば早い
- 設置中は射撃できない。敵が来る前に打ち終える判断が隊長 AI の仕事

### 2.2 建造物のエンティティ

```rust
pub struct Structure {
    pub id: StructureId,
    pub kind: StructureKind,
    pub segments: Vec<(Vec2Fx, Vec2Fx)>,  // 線分の列
    pub hp: Vec<u16>,                      // セグメントごとの耐久
    pub completion: u16,                   // 0..1000
    pub owner: FactionId,
}
```

建造物は破壊されうる（敵の工兵が壊す、突撃で杭が折れる）。
`completion` に応じて効果が線形にスケールする。

## 3. 地形改修

### 3.1 架橋

川に仮橋を架ける。**会戦の勝敗を左右するボトルネック**を作る。

```
工数 = 川幅(m) × 400 man-s
```

- 幅 3 m の仮橋なら、**同時通過は 3〜4 人**。1,000 人の部隊が渡り切るのに
  数分〜十数分かかる
- 渡っている間の部隊は縦列で、隊列維持 −80%、防御 −50%。
  **渡河中を襲われるのが最悪の状況**
- 橋は破壊可能。渡っている最中に落とされると悲惨（両岸に分断される）
- 敵の工兵が破壊しに来る（`DestroyBridge` タスク）

### 3.2 渡渉点整備

浅瀬（`Ford`）をより渡りやすくする。石を敷き、川底を固める。

```
工数 = 幅(m) × 150 man-s
```

効果: 移動 550 → 800、隊列維持 400 → 650。

### 3.3 伐採

森を切り開いて射界と通路を作る。

```
工数 = 面積(m²) × 8 man-s   (DenseForest)
       面積(m²) × 4 man-s   (LightForest)
```

- `surface` を `Grass` に、`cover` を下げる
- 時間がかかる（100 m × 20 m の伐採 = 16,000 man-s = 100 人で 3 分弱）
- 伐採した木材は鹿砦・仮橋の材料になる（材料が近くにあると工数が下がる）

### 3.4 地形改修の即時性

地形グリッドの書き換えは**チャンク単位で描画に通知**する。
レンダラは変更されたチャンクのタイルテクスチャだけ焼き直す。

## 4. 攻城兵器の野戦運用

野戦での投射兵器は数が少なく、設置に時間がかかるが、**士気への効果が大きい**。

| 兵器 | 射程 | 発射間隔 | 設置時間 | 効果 |
|---|---|---|---|---|
| **マンゴネル** | 300 m | 90 s | 15 分 | 石を放物線で。着弾点半径 3 m に大ダメージ。士気ダメージ大 |
| **トレビュシェット** | 400 m | 240 s | 45 分 | 巨大。野戦で使うのは稀。設置が間に合えば強力 |
| **バリスタ** | 350 m | 45 s | 8 分 | 直射、単体貫通。密集列を貫く（1 発で複数） |
| **スプリンガルド** | 250 m | 30 s | 5 分 | バリスタの小型版。移動が容易 |

### 4.1 運用

```rust
pub struct SiegeEngine {
    pub kind: SiegeKind,
    pub pos: Vec2Fx,
    pub facing: Brad,
    pub crew: Vec<SoldierId>,        // 必要人数を満たさないと稼働しない
    pub setup_progress: u16,         // 0..1000
    pub reload_progress: u16,
    pub ammo: u16,
    pub state: EngineState,          // Packed | SettingUp | Ready | Reloading | Firing
}
```

- **移動には牽引が必要**。移動速度 0.5 m/s（人力）または 1.5 m/s（牛馬）。
  移動中は `Packed` 状態で使えない
- 泥・急斜面（tanθ > 0.15）・森では移動不可。地形が配置場所を制限する
- 要員が死ぬと稼働率が落ち、一定を割ると停止。**要員を狙うのが対抗手段**
- 弾薬は有限（石 20〜30 発）

### 4.2 士気効果

投石の着弾は物理ダメージ以上に士気を削る。

```
着弾点半径 15 m の全兵士に  morale -= 45 × (1 - dist/15)
```

数十人しか殺せなくても、密集した部隊を動揺させる価値がある。

## 5. 兵站支援

### 5.1 矢の補給

**射撃戦の継続時間を決める、最も実効性の高い工兵タスク。**

```rust
pub struct SupplyDepot {
    pub pos: Vec2Fx,
    pub arrows: u32,
    pub bolts: u32,
    pub stones: u32,
}
```

- 荷車（`SupplyDepot`）が戦線後方に置かれる
- 工兵が矢束（1 束 = 24 本、重量から 1 人 4 束まで）を depot から前線の弓兵 Unit へ運ぶ
- 往復時間 = 距離 / 歩行速度 × 2。500 m 離れていれば往復 15 分
- 弓兵の矢が 20% を切ると Unit が補給要求を出し、工兵 AI がタスク化する
- 補給が届かなければ弓兵は撃てなくなる

**depot の位置決めが戦術判断になる。** 前に置けば補給が速いが、
騎兵に襲われれば失う。後ろに置けば安全だが補給が遅い。

### 5.2 負傷者回収

- `Downed` の兵士を担架で後方に運ぶ（2 人 1 組、速度 0.6 m/s）
- 回収された兵士のうち一定割合（`recovery_rate`、重傷度による）が
  時間経過後に軽傷で復帰する
- 回収は**士気に効く**: 味方が助けに来ることが見えると周囲の士気が上がる
  （+15）。逆に負傷者が放置され続けると士気が下がる
- 交戦中の場所には工兵が入れない（`self_preservation` 判定）

### 5.3 修理・再武装

- 破損した盾・折れた武器の交換（携行予備から）
- 落馬した騎士に予備馬を届ける（軍馬は貴重なので数が限られる）
- 攻城兵器の修理

## 6. 工兵 AI

工兵 Unit の隊長は、タスクキューから次にやることを選ぶ。

```
score(task) =
      task.priority × 4
    + tactical_value(task)          // 上位指揮官が「橋が要る」と判断していれば高い
    + (1000 - travel_time)          // 近い作業を優先
    - danger_at(task.area) × w(self_preservation) × 3
    - work_remaining / 100
```

上位指揮官は `Objective` から工兵タスクを生成する。

| 指揮官の目的 | 生成される工兵タスク |
|---|---|
| `DefendHighGround` | 稜線の前面に堀・杭列。射界確保の伐採 |
| `SeizeTerrain { bridge }` | 架橋、または渡渉点整備 |
| `Delay` | 敵の進路に鹿砦・堀。橋の破壊 |
| 弓兵中心の布陣 | 杭列、パヴィス設置、矢の前送 |
| 会戦の推移（射撃戦が長引く） | 矢の補給を最優先に昇格 |
| 損害の増大 | 負傷者回収の優先度上昇 |

## 7. 会戦前フェーズ

シナリオは**会戦開始前の準備時間**を持てる（既定 0〜120 分）。

- この間、両軍の工兵は築城を進める
- 準備時間は「敵の到着までの猶予」としてシナリオで与えられる
- プレイヤーは準備時間中も指揮官に憑依して工兵タスクを指示できる
- 準備が十分なら（アジンクールの英軍のように）防御側が圧倒的に有利になる

準備時間は倍速で早送りできる（既定 32x）。UI は築城の進捗を表示する。
