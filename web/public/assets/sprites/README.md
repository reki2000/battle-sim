# 人物スプライトシート

ImageGen で事前生成した人物アセットです。ビルド時に画像を生成しません。

## シート形式

各シートは 8列 × 4行です。

- 列: 南、南東、東、北東、北、北西、西、南西
- 行: アニメーションの4つの連続位相
- 4行目は1行目の複製ではありません。`0 → 1 → 2 → 3 → 0` と再生したときに、
  4つの異なるポーズが連続するように分割しています。
- 出力サイズは 1536 × 1024 px。1コマは約192 × 256 pxで、目標の200 × 300 pxに近い
  実用的なシートサイズです。

## 現在の生成済み役職

`heavy-infantry/` と `spearman/` に以下の5行動を収録しています。

- `idle.png`: 待機
- `walk.png`: 歩行
- `run.png`: 走行
- `combat.png`: 戦闘
- `work.png`: 工作

役職の予定リストは、重装歩兵、槍兵、パイク兵、長弓兵、弩兵、重騎兵、軽騎兵、工兵です。
現在は重装歩兵と槍兵が揃っており、残りの役職も同じ 8×4 シート形式で追加します。
